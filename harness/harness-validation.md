# 허들링 화면 설계 하네스 — 검증과 리뷰 (R8)

## 하네스 자체 검증

첫 실행은 샘플 요청 1개로 S1~S5 전체 파이프라인을 처음부터 끝까지 수동으로 돌려보고 확인한 뒤 실사용으로 전환합니다.

## 판정 결과 기록/보존

모든 `review-report.md`는 `harness/<slug>/`에 삭제 없이 보존합니다. 실패 이력도 남겨서 나중에 감사(audit)할 수 있게 합니다.

## SSOT 변경 반영

`docs/design.md`, `docs/story-service.md`가 바뀌면 별도 버전 고정 없이, 판정 에이전트가 다음 실행부터 자동으로 최신 버전을 참조합니다.

## 사람의 최종 리뷰 지점

- S3 컨펌 게이트 (디자인 승인 시점)
- S5 판정 리포트 확인 시점

이 두 곳에서 사람이 최종 확인합니다.
