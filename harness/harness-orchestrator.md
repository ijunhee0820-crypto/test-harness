# 허들링 화면 설계 하네스 — 오케스트레이터 재확인 (R7)

## CLAUDE.md 역할

오케스트레이터(CLAUDE.md)는 파일을 직접 편집하지 않습니다. 트리거를 받아 작업 에이전트/판정 에이전트를 순서대로 호출하는 라우팅 전용 역할만 수행합니다.

## 내용 구성

CLAUDE.md에는 R1~R7 전체 내용을 인라인으로 복붙하지 않습니다.

- 인라인 요약: 파이프라인 순서(S1~S5), 게이트 조건, 에이전트별 편집 경계
- 참조 링크: 나머지 세부 내용은 `harness/harness-*.md` 각 파일을 링크로 참조

## 동시 진행

여러 요청(slug)이 동시에 진행될 수 있습니다. 각 요청은 독립된 `harness/<slug>/` 폴더를 가지므로 병렬 진행이 가능합니다. 단, 사람 승인이 필요한 S3 게이트는 한 번에 하나씩 순차적으로 처리합니다.

## 게이트 실패/복귀 감지 방법

오케스트레이터는 아래 두 가지로 다음 행동(진행/복귀)을 결정합니다.

- 각 단계 산출물 파일의 존재 여부
- `review-report.md`에 기록된 판정 결과(PASS/FAIL)
