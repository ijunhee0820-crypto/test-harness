# 허들링 앱 — 핵심 유저스토리 & 준수 사항

> 출처: `docs/prd.md`

## 유저스토리

| # | 유저스토리 (PRD 출처) |
|---|---|
| 1 | 무료 학습자가 허들링의 AI/Figma/자동화/바이브코딩 콘텐츠를 부담 없이 둘러본다. (3-1) |
| 2 | 유료 멤버가 강의자료·다시보기·템플릿·프롬프트·스킬 파일·미션을 한곳에서 확인한다. (3-2) |
| 3 | 실험하는 멤버가 매달 만든 프롬프트·스킬 파일·자동화 템플릿·업무 적용 사례를 제출하고 기록한다. (3-3) |
| 4 | 판매를 원하는 멤버가 자신이 만든 자료 중 일부를 선택해 판매 신청한다. (3-4) |
| 5 | 운영자가 무료/유료/판매용 자료를 구분 관리하고, 멤버가 올린 자료를 검수한다. (3-6) |

> 3-5(구매자)는 PRD에 "이번 범위 제외 · Phase 2"로 명시되어 있어 제외했습니다.
> 2번은 PRD 원문(3-2)에 있는 "피드백 확인"을 뺀 버전입니다. 9장 MVP 결정사항(524~531줄)에서 미션 피드백 기능이 MVP 제외로 명시되어 있어 MVP 범위에 맞춰 조정했습니다.

## 이 서비스에서 어기면 안 되는 것

1. **개인정보·고객정보·회사기밀·타인의 저작물은 판매 자산에 포함될 수 없다.** (14장, 723줄 / 6-7절 296~298줄)
2. **판매 자산은 반드시 운영자 검수를 통과해야 한다.** (14장, 722줄 — 검수 없이는 판매/공개 불가)
