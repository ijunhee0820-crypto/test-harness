# 허들링 화면 설계 하네스 — 게이트 (R5)

## 기계가 셀 수 있는 통과 조건 (S5 자동 체크)

design.md 기반 조건입니다.

- 모서리(border-radius)는 `0 / 16 / 24 / 9999`만 허용
- 색상은 design.md 토큰만 사용, accent blue(#0066ff)는 화면당 1~2개 요소 이하
- box-shadow 사용 0건 (그림자 없음)
- 프레임 390×844 기준, 최소 360px 폭에서 가로 스크롤 없음
- 폰트는 Pretendard만, letter-spacing 0

## ★ R1-A "어기면 안 되는 것" 위반 시 걸리는 조건

`story-service.md`의 금지 사항과 연결된 조건입니다.

- (a) 목업/예시 콘텐츠에 실명·연락처·주민번호 패턴 또는 "기밀" 표시 문자열이 발견되면 게이트 실패 (개인정보/회사기밀 금지 위반)
- (b) "판매 신청" 관련 화면 플로우에 상태값이 `검수대기 / 수정요청 / 승인됨 / 반려` 중 하나라도 빠져 있거나, 검수 없이 "판매중"으로 바로 전이하는 화면이 있으면 게이트 실패 (운영자 검수 필수 위반)
